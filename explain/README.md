# 🚀 Besu Learning Path — From Zero to Contributor

Welcome! This folder contains a **complete, sequenced learning guide** to take you from absolute blockchain basics all the way to contributing to **Hyperledger Besu** — an enterprise-grade Ethereum client written in Java.

This guide is designed for the **LFX Mentorship Program (LFDT)** contributors who want to be ready to contribute to Besu starting April.

## 🎯 Your Goal

By the end of this guide, you will:

- ✅ Understand blockchain and Ethereum from first principles
- ✅ Know how the EVM, smart contracts, and transactions work
- ✅ Understand Besu's full architecture and internals
- ✅ Be able to run Besu locally and set up a private network
- ✅ Navigate the Besu Java codebase confidently
- ✅ Know how to find issues, submit PRs, and contribute to Besu on GitHub
- ✅ Be LFX Mentorship ready!

## 🛠️ Prerequisites

Before starting, make sure you have:
- Basic programming knowledge (any language)
- Java installed (JDK 21+) — needed for Besu
- Git installed
- A GitHub account
- A terminal / command line familiarity
